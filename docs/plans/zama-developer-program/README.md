# Zama Developer Program — carpeta de aplicación

Preparación para entrar al **Bounty Track general** del Zama Developer Program
con el scheme `fhe-transfer` del facilitador.

**Veredicto corto:** la "Mainnet Season 4" es un bounty temático (PoolTogether
confidencial en Sepolia, deadline 2026-09-05) y **no aplica** a un facilitador de
pagos. El track correcto es el Bounty Track permanente — *tooling, documentation,
integrations* — que es rolling y no depende de la Season.
