What x402 is, in three sentences

Charging a few cents for one HTTP request used to mean an account, a card on file and a minimum invoice, so nobody charged for a request — they charged for a subscription.

x402 finally uses the HTTP status code 402 Payment Required that was reserved and never shipped: your endpoint answers 402 with the terms it accepts, the caller signs one of them off-chain — an EIP-3009 authorization, a signature that moves a stablecoin — and retries with that signature in a header.

This facilitator is the piece that turns that signature into money: it checks it (verify), it puts it on chain and pays the gas itself (settle), and it charges 0% for both.

The full protocol, with escrow and upto, is at /x402.

What this facilitator runs

One service, several products. Each card says what state it is in, because "deployed" and "ready for your money" are different claims and only one of them is worth making.

Product State What it is
x402 live The core: two calls, gasless for the buyer, 0% fee. Escrow and upto included as extensions of the same settle.
MCP live The same four calls as agent tools, over one stateless endpoint. Nothing to install.
ERC-8004 live Agent identity and reputation, gas paid by us — including who the chain records as the author of a rating, which is not always who wrote it.
Bazaar live A swept catalog of payable endpoints, with the share each upstream feed contributes stated next to the totals.
DX402 beta The response you paid for, sealed to your own public key and anchored. Recovered later with the same wallet.
Zama FHE experimental Confidential amounts on fhEVM, on Ethereum Sepolia only. Encrypted end to end and not ready for anybody's mainnet money.

Start in one line

Both SDKs already point at this facilitator. There is nothing to configure until you want a different one.

TypeScript

npm install uvd-x402-sdk

// Client: create a payment with any stablecoin
import { createPayment } from "uvd-x402-sdk";

const payment = await createPayment(wallet, {
  recipient: "0xYourWallet",
  amount:    "10.00",
  tokenType: "eurc"          // usdc | eurc | ausd | pyusd
});

// Server: verify it
import { verifyPayment } from "uvd-x402-sdk";

const result = await verifyPayment(
  request.headers["X-PAYMENT"],
  { maxPrice: "10.00", recipient: "0xYourWallet" }
);

Python

pip install uvd-x402-sdk

# Which stablecoins a chain takes
from uvd_x402_sdk import get_supported_tokens, get_token_config

tokens = get_supported_tokens("ethereum")
# ['usdc', 'eurc', 'ausd', 'pyusd']

eurc = get_token_config("base", "eurc")
# TokenConfig(address="0x60a3...", decimals=6)

# Server: verify it
from uvd_x402_sdk import verify_payment

result = verify_payment(
    request.headers["X-PAYMENT"],
    recipient="0xYourWallet",
    max_price="10.00",
)
